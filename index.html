Free QR Code Generator

Open source, runs 100% in your browser. Nothing you type is uploaded, there is no sign-up and no tracking, and it keeps working offline once loaded.

Need to change where a printed QR code points? Codes made here are static: the content is baked in and works forever, but can't be edited. If you need an editable (dynamic) QR code with scan counts and no monthly subscription, see ForeverQR, from the same authors: one-time payment, the code never expires.

Static QR codes never expire

Every code generated on this page stores its content directly in the black-and-white pattern. There is no redirect server in the middle, so the code keeps working as long as the destination exists — no account or subscription can switch it off.

Privacy

The page is a single static HTML file plus the MIT-licensed qrcode-generator library by Kazuhiko Arase. It makes no network requests after loading: WiFi passwords and contact details never leave your device. View the source on GitHub.
